## 二、今日结论（可直接引用的数字）

### 2.1 1T2R 方位角在本硬件上不可用

- `20261113-133307_S01` 的 `rest0` 段（93 帧、无人动）方位角跨度已达 **159.4°**，`dphi` 在 ±3.14 满幅跳。
- 跳 146–165°、左/右 43–165°、弯腰 148–156°，**各组无差异**；方位角连「有人/没人」都分不开。
- 根因：`dphi_band` 是带内全部（chirp × bin）的功率加权相位差，而带内九成以上能量挂在零多普勒（静态杂波）上（`band_share` 中位 0.01–0.17）。
- 只保留非零多普勒单元的 `mv_feats` 仍是噪声：`ang_mv` 中位 30–52°、跨距 150°、每块 20–44 个不同取值。
- **结论**：所有判据只依赖多普勒轴（`v_r`、`doppler_width`），与板子正放/竖放无关；1T2R 拿不到可用俯仰角。

### 2.2 谱宽可分「径向 / 切向」，但不能分「跳 / 蹲」

| 对比 | 数字 | 结论 |
|---|---|---|
| 静息 `nz_p90` | 0.037 | 与动作 0.52–0.94 完全分开 |
| 切向 `w90` | 0.15–0.20 | 门限 0.22 |
| 径向 `w90` | 0.29–0.54 | 与切向留 0.09 空隙 |
| 大幅跳 vs 深蹲 `w90` | Cohen d = +0.06 | 完全重叠 |
| 小跳 vs 小蹲 `w90` | 0.21–0.23 vs 0.17–0.21 | 方向相反，不可用 |

### 2.3 跳 / 蹲改用「径向速度同号段长度」

为什么不用幅值/位移：

- 蹲的起身正峰 **0.88 m/s**，比跳的正峰 0.46 m/s 还大；
- 大跳蓄力位移中位 **38.2 cm**，比深蹲 29.4 cm 还深。

实测分段（7.73 fps，1 帧 = 129.5 ms，允许段内 1 帧抖动）：

| 动作 | 最长负段 `nb` | 最长正段 `pb` |
|---|---|---|
| 轻跳 `jump_k` | 1–2 帧 | 0–2 帧 |
| 深蹲 `duck_l` | 4–6 帧 | 4–6 帧 |

**分界 3 帧 ≈ 0.39 s。** 因果 EMA（`alpha=0.5`）解决浅蹲 `v_r` 符号抖动：浅蹲 `|v_r|` 中位 0.401 m/s、EMA 前 `nb=0`，EMA 后 3–4。

## 三、判断条件（现行提案，待小组确认）

```
nz_p90 < 0.50                 → none
w_p90  < 0.22                 → lateral（切向，左/右）
max(nb, pb) >= 3              → duck
pb >= 1                       → jump
否则                           → none
```

逐帧状态机：

```
IDLE  --原始 v_r < -0.15-->  NEG(nb=1)
NEG   --vs < -0.15, nb+1-->  nb>=3 → DUCK → SUPPRESS
NEG   --vs > +0.15-->        JUMP
NEG   --|vs|<0.15 连续 3 帧--> nb>=3 → DUCK；nb>=1 → JUMP；否则 IDLE
SUPPRESS --nz<0.30 连续 6 帧--> IDLE
任意事件后冷却 8 帧（1.03 s）
```

| 参数 | 值 | 依据 |
|---|---|---|
| `NZ_T_ON` | 0.30 | 静息 0.00–0.03 / 动作 0.6–0.9 |
| `NZ_P90` | 0.50 | 同上 |
| `W_LAT` | 0.22 | 切向 0.15–0.20 / 径向 0.29–0.54 |
| `ALPHA` | 0.5 | 0.4 漏浅蹲、0.6 拖长大跳 |
| `V_T` | 0.15 m/s | 平滑后静息 \|vs\| < 0.05 |
| `NB_DUCK` | 3 帧 | 跳 1–2 / 蹲 3–6 |
| `QUIET` | 6 帧 | 覆盖起身后摇 |
| `COOLDOWN` | 8 帧 | 一次完整跳 4–6 帧 |

设计要点：

1. 动作开始后不再检查 `nz`——腾空瞬间 `nz` 会掉到门限以下，用它维持会掐断跳跃正段（实测 `jump_k` 有 3 块因此无事件）。
2. 触发用**原始** `v_r`，不用 EMA——EMA 冷启动把首帧削半（0.19 → 0.096），轻跳会漏。
3. `nb >= 1` 的兜底 JUMP——短负段后平静且未转正，说明 7.7 Hz 漏掉上冲，负段短即快速动作。

## 四、失败边界与证据纪律

- **自然大跳 = 浅蹲（物理不可分）**：两者在 `nb`、`negPk`、位移上全部重叠，因为动作本身就是「浅下蹲 + 起身」，只是意图不同。这是任务本身的边界，不是调参能解决的。
- 全部 96 样本为**单人同日**采集；换人后是否成立未验证，不得写成已验收。
- 四批数据目录：`20261113-133307_S01`（37 块）、`134832_S01`（21 块）、`140614_S01`（33 块）、`142228_S01`（25 块）；两个 `VOID` 因雷达歪斜/掉线作废，不接入评估。
