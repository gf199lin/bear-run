# 双板标定实验结果（1T2R 测左右 / 2T4R 测上下）

> 本文只记录**已执行的测量**与**据此得出的判断**。未执行的部分明确标为「未验证」。
> 阈值类数字均为本项目提案，**待小组确认**。

- 采集会话：`data/calibration/20261029-190335`
- 采集时间：2026-10-29 19:03
- 样本规模：6 类动作 × 4 次重复 = 24 个样本
- 采集方式：`tools/calib_collect.py`（双板并发、语音引导、站位循环每次从中性位出发）
- 分析工具：`tools/calib_analyze.py`，结果 `outputs/calibration-analysis/analysis-20261029-190335.json`

## 采集条件

| 项 | 1T2R | 2T4R |
|---|---|---|
| 端口 / 芯片 | COM3 / CP2102 | COM4 / FT232 |
| 波特率 | 921600 | 1500000 |
| 帧率（实测） | 7.7 Hz（38~39 帧 / 5 s） | 1.9 Hz（9 帧 / 5 s，19 帧 / 10 s） |
| 摆放 | 水平 | 竖直，4 个 RX 天线竖排 |
| 站位 | 雷达正前方约 2 m，横向跨步 0.5~0.8 m | 同左 |

动作序列（每轮）：IDLE → 左移 → 回中 → 右移 → 回中(不记录) → 跳 ×3 → 蹲 ×3。
跳/蹲每段延长至 10 s，因为 1.9 Hz 下 5 s 只有 9 帧。

## 1T2R（水平放置）：左右识别可用

特征：零多普勒、能量最强距离门上的两通道相位差，逐帧计算后做**圆统计**（不能对复数 IQ 直接平均，相位快速变化时会互相抵消）。

| 动作 | 圆均值 (rad) | 段间一致性 R | 判定 |
|---|---|---|---|
| LANE_RIGHT | 0.234 | 0.997 | 稳定 |
| LANE_CENTER | 1.231 | 0.993 | 稳定 |
| LANE_LEFT | 2.065 | 0.982 | 稳定 |
| IDLE | 0.790 | 0.511 | **不可靠** |
| JUMP | 0.932 | 0.995 | 稳定 |
| DUCK | 1.036 | 0.999 | 稳定 |

- 三类位置**单调有序**，左右跨距 **1.831 rad**，约为阈值间隔的 2 倍。
- Fisher 可分性 **4.46**（训练集表现，需独立数据复核）。

### 阈值提案（待小组确认）

| 条件 | 判定 |
|---|---|
| `θ < 0.732` | 右道 |
| `0.732 ≤ θ ≤ 1.648` | 中道 |
| `θ > 1.648` | 左道 |

阈值取相邻两类圆均值的中点。

### 必须注意的风险

1. **IDLE 组不可靠**：4 次重复中第 1 次为 −1.958，其余约 0.9，段间 R 仅 0.51。推测是按下启动后第一段人还没站定。
2. **静止态贴近分界**：IDLE 均值 0.790 距右/中分界 0.732 只有 **0.06 rad**。静止站立时人体轻微偏右即被判为右道。**状态机必须加滞回与最小切换间隔**，不能单帧直接判定。
3. 跳/蹲时 1T2R 读数 0.93~1.04，落在中道区间内。这是合理的（人在原地水平位置不变），可作为「跳/蹲时不触发换道」的天然保护，但**不能反过来用来识别跳/蹲**。

## 2T4R（竖直放置）：竖直方向**不可用**

### 硬件事实

2T4R 内部 4 个天线**竖排**，从雷达面板引出的线向下延伸。因此通道相位差反映**俯仰角**，对水平方位（左右）不敏感——这与实测完全一致：

| 动作 | bin13 相位差 |
|---|---|
| LANE_LEFT | −0.331 |
| LANE_RIGHT | −0.227 |

左右几乎同值，**用 2T4R 辅助测左右这条路关闭**（物理限制，非算法问题）。若要用 2 个 Tx 做 MIMO 水平孔径，需拆 TDM 帧，每 Tx 仅剩约 0.95 Hz，代价不可接受。

### 竖直信息同样不可用

跳过前 3 个近场门后的圆均值：

| 动作 | 圆均值 (rad) |
|---|---|
| LANE_LEFT | 0.063 |
| LANE_RIGHT | 0.207 |
| LANE_CENTER | 0.523 |
| IDLE | 0.608 |
| **DUCK** | **1.426** |
| **JUMP** | **1.536** |

- 站立组（0.06~0.61）与动作组（1.43~1.54）可分，Fisher 18.82。**只能判断「有人在跳或蹲」，无法区分是哪个**。
- 跳与蹲均值仅差 **0.11 rad**，远小于类内波动。

### 尝试过并失败的两条独立路径

| 尝试 | 方法 | 结果 |
|---|---|---|
| 运动方向 | 相位时间序列 unwrap 后线性斜率 | JUMP `0.037/−0.666/−0.005/−0.006`，DUCK `−0.003/0.008/−0.065/0.019`，符号无规律 |
| 多普勒符号 | 正/负多普勒能量比 | **所有动作 0.02~0.07，含 IDLE 亦相同**，运动多普勒被零频压死 |

### 根本原因（数据证据）

- 零多普勒、门 0~1 占据 **86%** 能量，其相位差恒为 `0.000`（共模直流/近场泄漏）。
- 整帧能量约 **1.2e12**，其中零频分量约 1.2e12，人体回波比泄漏低 **30~50 dB**。
- 跳/蹲时峰值门在 3/4/7 之间乱跳，能量仅约站立组的 1/5，说明**人体回波未进入有效门**。

这是摆放几何 / 增益配置问题，软件无法补救。

## 结论

| 能力 | 状态 | 依据 |
|---|---|---|
| 左 / 中 / 右识别 | **可用** | 1T2R，段间 R > 0.98，跨距 1.83 rad |
| 检测「有跳/蹲动作」 | 部分可用 | 2T4R，站立与动作间隔 > 0.8 rad |
| 区分跳 vs 蹲 | **不可用** | 2T4R 仅差 0.11 rad，两条独立路径均失败 |
| 2T4R 测左右 | **不可用** | 天线竖排，俯仰轴 |

## 证据边界

- 以上均为**同一批数据上算出的可分性**，属训练集表现。真实准确率必须用**独立采集**复核。
- 阈值为中点提案，未做 ROC 优化，未做滞回参数标定。
- IDLE 组数据质量差，判定静止态时不应依赖该组。
- 2T4R 失败结论**仅对本次摆放（竖直、约 2 m、当前增益）成立**，未验证其它几何。
