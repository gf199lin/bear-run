## 2. 本轮已得结论与证据

### 2.1 主判据：按"人当时在哪个方向"分组（这才是回答问题的口径）

```
人正对雷达时（方位角中位 |az|<=15°）：  60 帧 ｜ 保留 0.4 点/帧 ｜ 丢弃 5.7 点/帧
人站两侧时  （方位角中位 |az|>=30°）： 235 帧 ｜ 保留 2.8 点/帧 ｜ 丢弃 3.2 点/帧
```

| 量 | 正对 | 两侧 | 解读 |
|---|---|---|---|
| 保留点 | **0.4/帧** | **2.8/帧** | **正对时人几乎从画面上消失**（7 倍差） |
| 丢弃点 | **5.7/帧** | **3.2/帧** | 正对时反而**多丢了 78%** |

**关键推理**：两侧时"丢弃 3.2/帧"可视为 **j0 泄漏的本底水平**（那时人不在 j0）。
正对时丢弃升到 5.7/帧 ⇒ **多出来的约 2.5/帧就是人体回波落进了 j0 被切掉**。
⇒ 「正对看不到点」= **被屏蔽**，不是「没信号」。

### 2.2 方位角直方图（`-184545`）

```
  方位角            保留      丢弃
  -50~-40°        113       57
  -40~-30°        222      129
  -30~-20°        170      175
  -20~-10°         25      231
  -10~+0°          17      287     ← 正前方：保留几乎没了，丢弃最多
  +0~+10°          26      280     ← 同上
  +10~+20°         63      217
  +20~+30°        162      152
  +30~+40°        230      116
  +40~+50°         98       45
```
- 保留点在 **±30~45°** 出现双峰（人站两侧时能被看到）；
- **正前方 (±10°) 保留仅 43 个，而丢弃 567 个** —— 信号在，但被丢。

### 2.3 距离门分布（`-184545`）

```
  j0 0.34m   保留      0 ｜ 丢弃 1689      ← 被屏蔽的那一格
  j1 1.02m   保留    908 ｜ 丢弃    0      ← 绝大多数可见点在这里
  j2 1.70m   保留    119 ｜ 丢弃    0
  j3~j7      保留     99 ｜ 丢弃    0
```
**所有被丢弃的点 100% 落在 j0**（距离固定在一格）；**所有保留点都 ≥ j1**。
配合方位角铺满 ±50° ⇒ **j0 = 宽谱泄漏 + （正对时）人体回波，两者混在一格里，整门被 `min_range` 切掉**。

### 2.4 覆盖情况（用户说"右侧没走到底"）

直方图显示 **-50°~+50° 都有数据**，±50° 之外为 0。**视场只有 ±45°** ⇒ **可用视场已被覆盖完**，
"没走到底"**不影响主结论**；只是最右侧（+50° 附近）样本少（+40~+50° 仅 98/45 个）。
