## 1. 项目摘要

一款**用毫米波雷达做体感操控**的 3 车道无尽跑酷网页游戏：玩家用**左右移动、跳跃、下蹲**三个真实身体动作，控制卡通小熊「熊二」在森林跑道上躲避障碍、收集蜂蜜。雷达不可用时，**键盘与触屏是永远可玩的保底路径**。

- **目标用户**：校园休闲玩家（同学、室友）——碎片时间、**零安装**、随时可停；次要为课程评审师生（需扫码即玩、无需指导）。
- **MVP 最小价值**：验证「**身体动作能否被游戏顺畅消化**」这一核心命题。
- **交付形态**：单页 HTML5，双击即玩，可手机扫码；纯前端、无后端、无构建、**断网可玩**。

## 2. 问题与目标用户

| 项 | 内容 |
|---|---|
| 用户 / 场景 | 大学生休闲玩家；课间、宿舍、摊位，**1～2 分钟**一局 |
| 认定的问题 | 校园可及的休闲小游戏**清一色触屏手势、身体不动**；真体感游戏需**专用主机或摄像头**，门槛高 |
| 最小方案 | **不采集影像**的 1T2R 雷达 + **零安装网页**；无雷达时键盘/触屏保底 |

> **诚实声明**：「认定的问题」是团队**基于自身经验的归纳**，**尚未经用户调研证实**（见 §3）。我们把它当**待验证的假设**。

## 4. 现有做法与缺口

**手机休闲小游戏**——触屏手势、**身体不动**，与"动起来"的需求不匹配 ｜ **主机 / 摄像头体感方案**——需**专用硬件或安装**，摄像头方案还涉及场地、光线与**影像隐私**顾虑 ｜ **网页小游戏平台**——内容多，但**零安装 + 身体动作**的组合稀缺。

**切入缺口**：在**零安装的网页形态**下提供**不用摄像头的体感**——雷达只输出距离/速度特征、**不采集影像**，且键盘/触屏保底，演示不会翻车。本节判断证据强度均为 `[待核实]`，E-01/E-02 完成后须回来改写。

## 5. 拟议方案与 MVP 价值

**方案**：单页 HTML5 + 本地 Three.js（真 3D）+ 四源可切换输入层（键盘/触屏/真实雷达/雷达模拟器）。三车道吸附式换道 + 跳跃 + 滑铲，对应 4 类障碍与 4 个难度区域；血格、蜂蜜、红苹果、蜂蜜滑道构成生存与资源循环。

| ID | MVP 能力 | 价值 |
|---|---|---|
| **SC-1** | 三动作操控（左右/跳跃/滑铲），四源统一 | 验证「体感输入能否被游戏消化」的核心闭环 |
| **SC-2** | 三车道无尽跑道 + 4 类障碍与组合、分段解锁 | 提供持续挑战，也是测试三动作的必要场地 |
| **SC-3** | 生存与资源循环（血格、无敌帧、回血、蜂蜜、加速滑道） | 把"能玩"变成"想再玩一局" |
| **SC-4** | 完整对局流程 + 本地最高分 | 完整用户任务必须能从头跑到尾 |
| **SC-5** | 真实雷达接入与调试面板 | 无可观测手段就无法现场标定阈值 |
| **SC-6** | 熊出没式森林美术 + 搞笑角色动作 | 不接受简陋占位图形；障碍**可读性**决定玩法成立 |

**为什么值得做**：把"体感"的成本从「买主机 / 装摄像头」降到「打开一个网页」，且**无影像隐私顾虑**——这是校园场景下可传播的前提。

## 6. 可行性与风险

**已具备**：设备与授权软件到位（M-02）；原型已跑通全部玩法（M-03、T-01~T-04）；技术栈零构建、跨平台、断网可玩。
**最大不确定性**：**雷达能否稳定识别三个动作，尤其是垂直起跳**。

| 风险 | 等级 | 应对 |
|---|---|---|
| 雷达测不出垂直起跳（1T2R 无高度维） | **高** | 键盘版保底演示；E-03 前置验证；必要时由 B 做特征分类；**测不出则如实记录为"已移除"** |
| 证据缺失，被判为"无真实问题" | **高** | **提交前必须完成 E-01 ~ E-03** |
| 雷达延迟 > 300 ms 致手感不可用 | 中 | 与 A/B 确认帧率与延迟能否承诺；必要时做提前量补偿 |
| 正面安装致车道抖动 | 中 | 侧面安装 + 判定迟滞 |
| 手机端掉帧（真 3D 方案） | 中 | 限像素比、关阴影、控元素数 |
| 校园 WiFi 设备隔离 | 低 | 电脑开热点 |

**决策规则（提前定好，避免事后找理由）**：① 若 E-03 未通过 → 雷达跳跃降级为按键/触屏跳跃，雷达只做左右 + 下蹲，并在最终文档如实记录；② 若 E-01/E-02 显示用户不感兴趣 → MVP 定位改为「课程技术验证 Demo」，**不宣称用户价值**；③ 任一阶段未跑通 → **退回上一阶段演示**，键盘 + 触屏版本**永远必须可玩**。
