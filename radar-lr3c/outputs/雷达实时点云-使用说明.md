# 毫米波雷达 · 实时点云网站 —— 使用说明

> 目标：**随时打开都能用**。插上雷达就会自动识别串口，不需要改端口号、不需要看代码。
> 本文件面向使用者；技术记录见 `docs/progress-radar-pointcloud.md` §7.20。

---

## 1. 最快用法（推荐）

1. 把雷达 USB 插好（CP210x 设备；换 USB 口也没关系，端口号变了会自动认）。
2. 双击 **`outputs/雷达实时点云-一键启动.cmd`**（或在项目里双击 `radar-pointcloud/start_viewer.cmd`）。
3. 浏览器会自动打开 `http://127.0.0.1:8099`。

启动器会依次做四件事：检查 Python 依赖 → 体检串口（只读，不占端口）→
**复用已经在跑的服务**（不会起第二个进程去抢串口）→ 选空闲端口并起服务 + 打开浏览器。

停止服务：在启动器那个黑窗口里按 `Ctrl+C`，或直接关掉该窗口。

---

## 2. 页面上的状态怎么看

| 页面显示 | 含义 | 该做什么 |
|---|---|---|
| **实时数据流** | 雷达在出数据，画面就是真实点云 | 无需操作 |
| **已停止（点「开始」恢复采集）** | 服务在跑，但采集被停了 | 点页面上的「开始」 |
| **服务在线 · 串口 COMx 已连接，等待数据…** | 串口打开了但还没收到帧 | 等 1~2 秒；持续不动看下一条 |
| **服务在线 · 未检测到雷达串口** | 系统里没枚举到雷达串口 | 检查 USB 是否插好；设备管理器应出现 `Silicon Labs CP210x USB to UART Bridge`；缺驱动就装 CP210x 驱动（**不是 FTDI**） |
| **服务在线 · 串口 COMx 打不开：被其它程序占用** | 厂商工具或另一个服务占着串口 | 关掉 `ICL_mmWaveSensorDevTool.exe`，或关掉另一个 `server.py` / 启动器窗口 |
| **未连接点云服务** | 服务没启动，或你直接双击了 `viewer.html`（`file://` 打不开接口） | 双击一键启动器，再刷新页面 |

底部横幅与侧栏「链路诊断」会同时显示**当前系统枚举到的串口列表**和**最近一次失败原因**，
所以「为什么没数据」不用猜。

> 注意：页面在连不上服务时会显示一段**演示动画**，横幅会明确写「不是你的雷达数据」，
> 不要把它当成采集结果。

## 3. 其它启动方式（排查用）

在 `radar-pointcloud/` 目录下：

```bat
python server.py                     :: 默认：自动识别串口 + 自动开始采集
python server.py --port COM5         :: 手动指定串口（自动识别认不出时用）
python server.py --open              :: 启动后自动打开浏览器
python server.py --source loopback   :: 无硬件自检，看页面是否正常
python server.py --source replay --replay cap.bin   :: 回放录制文件
python server.py --no-autostart      :: 起来但先不采集（需要手动点「开始」）
```

HTTP 接口：`GET /status`（含 `src_diag` 链路诊断）、`POST /control {"action":"start"|"stop"|"reset"}`。

**串口是独占的**：同一时刻只能有一个程序打开 COM3。采集时厂商工具会连接失败，反之亦然。

## 4. 一键启动器做了什么（对照排查）

`radar-pointcloud/start_viewer.py`：

1. 检查 `pyserial` / `numpy` 是否安装，缺了给出 `pip install` 命令；
2. **串口体检**：只读枚举（不打开端口），按 `CP210x / Silicon Labs / ICL / DEV202` 线索判断哪个是雷达；
   认不出时说明原因（没有串口 / 有多个串口认不出）；
3. 探测 `8099` 起 5 个端口上是否已有本服务在跑：有就**直接打开已有服务**（不重复起实例抢串口）；
4. 否则选一个空闲端口启动 `server.py --source serial --port auto`，等 HTTP 就绪后打开浏览器。

---

## 5. 当前边界（诚实说明）

- 串口自动识别目前只在**单串口（COM3）**场景做过真机验证；多串口自动消歧未验证，
  此时请用 `--port COMx` 手动指定。
- 「换 USB 口后端口号变化」这一场景需插拔验证，尚未实测。
- 未创建桌面快捷方式；如需桌面入口，请把 `outputs/雷达实时点云-一键启动.cmd` 的快捷方式放到桌面
  （该文件必须留在项目内，靠相对路径找到代码）。
- 一键启动器不改雷达配置、不写寄存器，只负责起服务与打开页面。
