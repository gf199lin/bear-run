雷达桥接助手 —— 使用说明 (3步)
================================

为什么需要它？
  浏览器读串口的缓冲区只有 8KB，雷达一秒喷 65KB，稍微一卡就丢字节死链。
  这个助手用 1MB 大缓冲专职读串口，再把数据喂给网页 —— 卡死从根上消失。

使用步骤：
  1. 插好雷达板（确认没别的程序占用串口：关掉厂商工具、网页别用"浏览器直连"）
  2. 双击 start_bridge.bat
     看到「串口已打开, 数据畅通 ✓」就对了。这个窗口要一直开着。
  3. 打开网页 → 设置面板里 数据源 选「桥接助手(推荐)」→ 点「连接串口」

说明：
  · 选错串口？用命令行指定：  node bridge.js COM8
  · 网页断开后助手不会退出，雷达照读，网页点重连即可。
  · 助手窗口每10秒打一次心跳（累计字节/KB速率），数据通不通一眼看出。
  · 低速模式（网页设置里）用桥接时保持「关闭」即可，桥本身就不会卡。

技术备忘：
  依赖已打包在 _work/node_modules（serialport + ws），双击即用，无需联网安装。
  网页侧把 WebSocket 伪装成 Web Serial 端口（v0.7.0 WsBridge），配置宏/自愈逻辑不变。
