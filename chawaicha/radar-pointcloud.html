动作事件

快速上手

  1. 接线:DEV113P 直接用 USB 线连电脑,设备管理器中出现一个 USB 串行设备(COMx)。波特率选 1500000。
  2. 方式A·仅监听(推荐先试这个):打开厂商上位机,点「开始」确认能看到波形,然后完全退出上位机(雷达会保持数据输出)。回到本页选「仅监听」→「连接串口」→ 选择该 COM 口。
  3. 方式B·主动配置(推荐日常使用):选「主动配置」→「连接串口」,页面自动下发内置的 DEV113P 启动宏(从厂商上位机日志提取)并启动雷达,完全脱离上位机。
  4. 标定:玩家站到游戏位正中自然站立,点「标定站立位置」,保持 1 秒。
  5. 动作:左右移动超阈值产生 left/right 事件;跳跃(头顶快速接近雷达)产生 jump;下蹲(远离)产生 crouch。
  6. 对接游戏:填 WebSocket 地址后事件会以 JSON 推送;或先「录制事件」拿 JSONL 样本给游戏端开发。
  7. 模拟器:没有硬件时选「模拟器」模式即可体验完整链路(按 1/2/3/4 键模拟 左/右/跳/蹲)。

注意:Web 串口需要 Chrome / Edge 浏览器,且页面需以 https、localhost 或 file:// 方式打开。同一时刻只能有一个程序占用串口。
