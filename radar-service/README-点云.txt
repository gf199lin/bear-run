毫米波雷达 · 实时点云查看器  使用说明
================================================================

一、这是什么
  网页版雷达点云查看器：读取 1T2R（DEV202H / ICL1122）或 2T4R（DEV113P）
  的 USB 串口原始数据，在浏览器里实时显示点云。
  全程本机运行：不联网上传数据、不写注册表、不需要登录。

二、三步走（第一次用）
  1. 双击 1-setup.cmd
     安装 numpy / pyserial。看到 [通过] 就可以关掉这个窗口。

  2. 把雷达插上 USB
     设备管理器里应出现：
       1T2R  -> "Silicon Labs CP210x USB to UART Bridge"
       2T4R  -> "USB Serial Port"（FTDI FT232）
     没装驱动时会有黄色感叹号，见第四节。

  3. 双击 2-start.cmd
     它会自动识别串口、启动本地服务、并打开 http://127.0.0.1:8099
     页面里点「开始」即可看到点云（默认就是自动开始的）。

  建议第一次先双击 4-check.cmd 做自检：
  它只读 4 秒，直接告诉你「有没有出帧、帧率对不对、有没有点到人」，
  比盯着一个空白网页猜快得多。注意：自检会独占串口，先关掉网页服务再跑。

三、几个文件分别干什么
  1-setup.cmd          安装 Python 依赖
  2-start.cmd          连接雷达 + 打开点云网页（日常用这个）
  3-offline-demo.cmd   没插雷达也能看界面：回放合成数据
  4-check.cmd          雷达链路自检（串口列表 + 帧率 + 点数）

  server.py            本地网页服务 + 雷达数据管线
  start_viewer.py      启动器（依赖检查 / 串口体检 / 复用已有服务 / 开浏览器）
  check_env.py         环境检查与安装
  check_radar.py       链路自检
  viewer.html          点云页面（纯本地，不依赖任何 CDN）
  radar_*.py           串口、协议解析、DSP、动作识别模块
  sample-synthetic.bin 合成回放数据（人造目标，不含真人数据）

四、连不上 / 看不到点，按这个顺序查
  现象                          最可能的原因                   处理
  --------------------------------------------------------------------------
  窗口一闪而过 / 提示没有 Python   没装 Python 或没加 PATH        装 3.8+，勾选 Add to PATH
  [失败] 缺少 numpy / pyserial   依赖没装                       跑 1-setup.cmd
  串口列表 0 个                   线只供电 / 驱动没装 / 没插好     换数据线；装 CP210x 驱动
  串口列表有但"认不出"             电脑上还有别的串口设备          用 --port 指定，见第五节
  提示"串口被占用"                官方工具或别的窗口占着串口      关掉 ICL_mmWaveSensorDevTool /
                                                                 ONELAB / 串口助手 / 别的雷达桥接程序
  网页打开但一直"未连接"           选错口 / 波特率不对            跑 4-check 看证据，换 --port
  帧率只有理论值一半               USB 带宽 / 线材差               换短线、直插电脑、别用 hub
  有帧但没有点                    人静止正对雷达，被去杂波减掉     站 0.7~1.5 m，挥手或走动

  1T2R 理论帧率约 7.7 帧/秒；2T4R 约 1.9 帧/秒。
  这是设备本身的帧周期（1T2R 129.5 ms），不是程序卡。

五、手动指定串口
  电脑上若有多个串口设备（开发板、USB-TTL、打印机……），自动识别可能挑错。
  先跑 4-check.cmd 看它列出的串口和 VID:PID，再手动指定：

    双击开一个命令行，在本目录执行：
      python check_radar.py --port COM5
      python server.py --port COM5

  （start_viewer.py 不支持 --port，手动起服务后浏览器访问 http://127.0.0.1:8099 即可）

六、边界与注意
  * 本包只含程序与合成数据，不含实测采集数据、标定文件（calib.json /
    bg_baseline.json）和厂商授权文件，可以安全分发。
  * 点云是「距离 - 多普勒 - 角度」检测点，不是摄像头图像。
    点数少、会闪烁是正常的，不代表程序坏了。
  * 雷达不测垂直（俯仰）角，本程序也不显示高度。
  * 只支持 Windows（启动脚本是 .cmd）。其他系统可手动执行
    `python server.py --port COMx` 后访问 8099。

七、关于 2T4R（DEV113P）
  本包能自动认出 FTDI 口并按 2T4R 协议（1500000、55AA 帧、32 bin × 4 RX）解析，
  但注意两点：
  * 2T4R 需要按官方流程完成上电/配置后才会上行数据，开机不会自己吐帧；
    若官方上位机（ONELAB）里也看不到数据，那是硬件侧问题，不是本程序。
  * 本组对 2T4R 的链路验证仍在进行中，结论未定；点云主用 1T2R。
  2T4R 帧率约 1.9 帧/秒，比 1T2R 慢，这是板子本身的帧周期。

八、版本
  打包日期 2026-10-30
  支持 DEV202H(1T2R) 与 DEV113P(2T4R)
  已实测：1T2R 真机自动识别 COM3，7.4 帧/秒，37/37 帧检测到目标点；
         离线回放页面返回 200，27/27 帧有点。
  未覆盖：2T4R 当前无上行数据（与硬件侧验证状态一致），故其"出点"未验证。
