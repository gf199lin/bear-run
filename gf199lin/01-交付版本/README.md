# 01 · 交付版本

本目录放**可以直接分发**的三个包。所有包都已解压自测过，不依赖网络。

| 文件 | 大小 | 用途 | 怎么用 |
|---|---|---|---|
| `bear-run-20261020h-share.zip` | 0.7 MB | 对外分享版游戏（推荐发给老师/同学） | 解压后双击 `index.html` |
| `dual-radar-kit-v2.zip` | 1.7 MB | 双雷达联调工具包（桥接器 + 体检 + 回放） | 解压后按包内 `README.md` 启动 |
| `双雷达双开-组员包-20261030.zip` | 2.5 MB | 发给雷达组两人的一键启动包 | 解压后双击 `START-RADAR.cmd` |

## 分享版说明

`bear-run-20261020h-share.zip` 是 `h` 构建的对外版本，与在线版一致：

- 在线试玩：https://gf199lin.github.io/bear-run/
- 键盘：`←` `→` 换道，`↑` / 空格 跳跃，`↓` 滑铲，`P` 暂停
- 无硬件体验体感：主菜单 → 输入源 →「雷达模拟器」

## 为什么单独放这三个

其余 6 个历史构建在 [`../06-版本历史/`](../06-版本历史/)。
这里只保留**当前可用**和**交付给组员**的包，避免评审在一堆 zip 里猜哪个是最终版。

## 完整性校验

```powershell
Get-FileHash .\bear-run-20261020h-share.zip -Algorithm SHA256
```

如需与仓库 Release 页的产物比对，以 Release 说明中的哈希为准。
