## 怎么用

1. 下载 `index.html`；
2. 双击，用 Chrome / Edge 打开；
3. 主菜单直接开始，键盘 `←` `→` 换道，`↑` / 空格 跳跃，`↓` 滑铲。

不需要 `npm`、不需要本地服务器、不需要联网。

| 形态 | 适用场景 | 限制 |

| `07-离线单文件版/index.html` | 微信/邮件发给别人，双击就玩 | 不含雷达调试页与回放数据 |

## 已知限制（必须说明）

- **雷达实时功能需要本地服务**（`ws://127.0.0.1:8766`），单文件版本身不带服务，
  所以离线场景默认是**键盘模式**可玩；要接雷达仍需用 `01-交付版本` 的完整包。
- 文件里保留了 `?input=replay` 的回放入口，但回放数据 `_radarreplay/*.js` **没有内联**。
  只有在手动加 `?input=replay` 时才会去加载它，缺失时该模式不可用，**不影响正常游戏**。
- 代码中含内网联调地址 `ws://192.168.1.7:8766/8767`，这是当时现场雷达的局域网地址，
  换网络后需要在设置里改，不属于账号或密钥。
