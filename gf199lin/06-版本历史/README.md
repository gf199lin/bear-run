## 版本选择建议

- **要给老师/同学玩**：用 `01-交付版本/bear-run-20261020h-share.zip`，不要用这里的开发包；
- **要复现某个历史问题**：按上表找到对应版本解压，配合 `04-工具与脚本/` 的脚本；
- **要对比改动**：同一目录下相邻两个 zip 解压后做 `diff`，比看 commit 更直观。

## 已知问题（截至 h）

- 跳/蹲为实验功能，真机未验收，校准不通过会自动停用并退回键盘；
- 左右换道依赖现场校准，移动雷达板后需重新校准；
- 单雷达模式下不会产生跳/蹲事件（上下维度在进解码器前被清零）。

以上不是"待修 bug"，而是当前数据条件下的**设计边界**，详见
[`../03-雷达评估与校准/radar-calib-v2.md`](../03-雷达评估与校准/radar-calib-v2.md)。
