# 1T2R 最佳中线：实测 +8°，「45°」假设被推翻

> 2026-11-03。记录一次「先假设、再实测、被数据推翻」的完整过程。
> 证据等级：`find_best_az.py` 现场扫描，2765 点。**可复现**。

---

## 1. 结论

| 项 | 实测值 |
|---|---|
| 峰值方位角 | **+8.0°** |
| 半高全宽 FWHM | **约 20°**（左右各约 10°） |
| `\|az\| > 45` 的点占比 | **12%**（2765 点中 330 点） |
| 建议 `angle_max` | **45°**（不需要放宽） |

**中线配置**：`radar-pointcloud/center.json` → `1t2r.az_deg = 8.0`。

## 2. 被推翻的假设

采前口述：「1T2R 只有斜着用，板子一侧靠近法线约 45° 时点云密度最大」，
因此一度把 +45° 设为显示中线。

实测结果在 +8°，且 45° 附近（+40~+55）合计不到 3%。这不是"差一点"，
是**两个完全不同的方向**。

### 最可能的三种解释（按可能性排序）

1. **45° 是物理摆角，不是 az 读数。** 板子相对人体/墙面斜放了 45°，
   而雷达自己测到的方位角仍在法线附近（+8°）。人眼看到的"偏 45 度"
   与雷达坐标系不是一回事。
2. **扫描时的站位与提出假设时不同。** 如果这次人站在别的位置，
   测到的 +8° 只是"这个位置"，不代表雷达的最佳方向。
3. **板子被移动过。** 假设来自更早的安装状态。

**待确认**：扫描时人是否站在当初观察到"最密"的那个点上。
若否，需回到那个点重扫一次（`--save` 会覆盖 center.json）。

## 3. 为什么这个结果反而是好消息

原假设若成立（最佳区贴在 ±45 边界），左右移的可用空间会被砍掉一半，
一侧永远比另一侧差 —— 这与 10/22 数据「LEFT 25% / RIGHT 93%」的
方向性偏差在形态上是吻合的。

实测 +8° 且两侧余量充足（-37° ~ +37° 都在良好区），意味着：

- 左右各移 **0.3 m**（1.0 m 站位 ≈ ±17°）时，`az` 落在 **-9° ~ +25°**，
  **两侧都在主瓣内且基本对称**；
- 不需要为了"躲边界"而缩小位移，`--stride 0.3` 可以放心用。

## 4. 对代码的影响

| 项 | 结论 |
|---|---|
| `center.json` | `az_deg = 8.0`，`angle_max = 45.0` |
| `radar_dsp.ANGLE_MAX = 45` | **保持 45 不动**：只有 12% 的点在外，且多为尾部噪声 |
| `align_assist` | 显示「偏离最佳中线 = az_raw - 8°」 |
| `segment_capture` | 开场语音自检以 8° 为 0，超 8° 提示挪位置 |
| `radar_actions` / `server.py` | `angle_max` 保持默认 45 |

注意：`ANGLE_MAX = 45` **不再需要放宽**。放宽到 70 会把那 12% 的尾部
噪声放进来，反而让质心抖动。

## 5. 带宽的正确读法

FWHM 20°（±10°）**不是"人能移动的范围"**，而是「人体躯干在静止时
占据的角宽度」。1.0 m 站位上 ±10° ≈ ±0.17 m，正好是一个成年人的肩宽量级。

左右移判别靠的是**质心移动**，不是点云宽度：横移 0.3 m 让质心移动
17°，是 FWHM 的 1.7 倍，信号足够。

## 6. 工具

```powershell
# 扫描（若换站位/换人/换安装，重扫）
python radar-pointcloud\find_best_az.py --port COM3 --seconds 25 --save

# 对准（读 center.json，目标 |偏离| <= 5°、|px| < 0.10 m）
python radar-pointcloud\align_assist.py --port COM3 --target-az 5 --target-px 0.10

# 采集（自动读中线，开场语音纠偏）
python radar-pointcloud\segment_capture.py --port COM3 --board 1t2r `
  --distances 1.0 --actions left,right --reps 8 --stride 0.3 `
  --auto --lead 40 --outdir data\lr3
```
