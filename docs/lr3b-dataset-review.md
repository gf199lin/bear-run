## 2. 「检出率 48%」的真相：距离是被量化成两个 bin 的

逐帧统计（`--band` 不设，只看有没有点）：

```
r 分位 5%=1.02  25%=1.02  50%=1.02  75%=1.70  95%=1.70
```

不是连续分布，是 **1.02 / 1.70 两级**，正好差 0.68 m（距离分辨率）。

人站在 1.0 m，身体厚度让点在这两个 bin 之间跳。而 meta 里写死的
`band=[1.36, 2.04]` 只框住 1.70 那个：

- 落在 1.02 的帧 → 全判「没人」→ 检出率 48%
- RIGHT 段恰好以 1.02 为主 → 只剩 31 帧

**这不是算法问题，也不是人没站好。** 换成 `--band 0.90,1.80` 后：

| | 修带前 | 修带后 |
|---|---|---|
| LEFT 帧 | 137 | **163** |
| RIGHT 帧 | 31 | **162** |
| LEFT dev 中位 | +0.236 | **+0.256** |
| RIGHT dev 中位 | -0.365 | **-0.222** |
| 静息 \|dev\| p90 | 0.393 | 0.333 |

修带后 LEFT/RIGHT 帧数几乎相等（163 vs 162），dev 幅度也基本对称
（0.256 vs 0.222），这是「左右位移对称」的硬指标首次达标。

## 3. 可分性

```
LEFT  dev IQR [+0.103, +0.449]
RIGHT dev IQR [-0.280, -0.140]
```

**两段 IQR 完全不重叠**，中间界约 0。帧级 10% 分位：LEFT +0.009、
RIGHT -0.069，所以 0 附近有一个干净的分界带。

在线规则（`lane_eval.py --band 0.90,1.80`）：

```
LEFT  8/8 = 100%
RIGHT 4/8 =  50%
合计 12/16 = 75.0%   延迟中位 1.68 s   误报 12
```

对比旧数据 59.1%（LEFT 25.5%）；这批 75%，且 LEFT 首次满分。
剩下的 RIGHT 一半是**规则阈值偏保守**（`xbase` 要 dev 更负才触发），
不是数据不可分——离线可分性已经证明特征存在。

注意：`lane_separability.py` 报的「单特征最佳 100%」是同批数据上
扫阈值得到的乐观上界，跨人/跨站位不可直接引用，判据仍以 IQR 和
分位数看。

## 4. 电脑目标排查：这次没有出现，但 -29° 是错的

用户指出：雷达斜放，人站在一侧，**另一侧是电脑，完全静止**。
担心 `align_assist` 取「最强点」时锁到电脑。

用「分段时间占比」判据（静止体在 静息/左/右 三类帧中的出现率应
近似相等；人只在动作段出现），逐 2° 桶统计：

```
az    REST%  LEFT%  RIGHT%   判定
-4       8      1      21    RIGHT 才出现 → 是人（右移位置）
+14     16     31      19    LEFT 集中 → 是人（左移位置）
+8      19     14      15    REST 也高 → 是人的静息位置
+40 以外  <1     <1      <1   没有稳定目标
```

**这次数据里没有常驻静止目标**（没有哪个桶在静息/左/右都高），
所以这批用「最强点」没有被电脑污染。

但 `align_assist` 那次测出的 **-29.15° 在数据里几乎不存在**
（az 最小 -20°，且占比 1%）。它是误锁/误测，已在 `center.json`
中改为 **+9°**（静息中位）。

因此规则是：

| 场景 | 做法 |
|---|---|
| 采集/对准 | 必须 `--exclude-az lo,hi` 排除电脑那侧扇区 |
| 判定「是不是人」 | 看分段时间占比，不看能量 |
| 中线 | 以静息段 az 中位为准，不采信单次 align 读数 |

## 5. 已落地的代码

- `radar_dsp.PointCloudProcessor(exclude_az=(lo,hi))`：扇区内点直接丢弃
- `segment_capture --exclude-az -90,-45`：透传到 DSP
- `segment_capture --auto-band`（默认开）：lead 段实测 r 中位数定带，
  覆盖 1.02/1.70 两个 bin
- `lr_guide.py` + `guide.html`：浏览器引导页，**这是后续采集的标准形态**
- `lane_eval --band`、`lane_separability --band`：诊断时不改原始 meta
