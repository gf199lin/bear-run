| 批次 | 双 RX 平均相干性 | 空帧（能量为 0） |

| `20261112-200211` | 0.848 | 0 |

| `20261112-205706` | 0.797 | 0 |

相干性按 `|⟨a,b⟩| / (‖a‖·‖b‖)` 逐帧计算后取均值，其中 `a`、`b` 为两个接收通道的复数样本。
本批五组均落在 **0.79~0.86**，说明两路接收通道相关性强但并非完全一致（天线间距与相位噪声所致），
不影响本次判据——本方案只用单通道功率谱，不做跨通道相位差。

**五批均为 0 空帧**，没有出现掉包导致的零能量帧。

## 三、峰值 bin 恒为 2

四批有效数据（`200831` / `201355` / `203419` / `205706`）的距离维能量峰值**全部落在 bin 2**。
这与「人站在约 1.2 m、雷达离地约 0.5 m」的几何一致，也再次说明：

- 目标距离在本批中没有可用的变化量（跳/蹲的高度变化不体现在距离 bin 上）；
- 因此**不能用距离门或 bin 跳变做动作判据**，必须走多普勒。
