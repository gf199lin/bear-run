# 分析记录：1T2R 竖直方向判跳/蹲（2026-11-12，4 批有效 + 1 批自检）

> 输入：`data/vguide_1t2r/` 下五批采集（20:02 / 20:08 / 20:13 / 20:34 / 20:57）
> 摆法：雷达离地约 0.5 m，板面向上抬 15–20°，人站约 1.2 m
> 方法：多普勒谱宽 + 零多普勒外能量门控，事件级回放
> 结论：**四批合计 46/49 = 93.9%，每批跳/蹲谱宽两簇完全分开**

## 一、为什么不用平均径向速度

帧周期 130 ms，一次跳/蹲在单个 CPI 内完成加减速，正负多普勒互相抵消。

| 段 | 零多普勒占比 | 正峰速度/占比 | 负峰速度/占比 |
|---|---|---|---|
| base1 | 97.4% | +0.38 / 0.3% | −0.38 / 0.3% |
| base2 | 99.5% | +0.19 / 0.0% | −0.19 / 0.1% |
| base3 | 100.0% | +0.19 / 0.0% | −0.19 / 0.0% |
| jump | 41.8% | +0.24 / 3.4% | −0.19 / 4.1% |
| duck | 43.8% | +0.19 / 3.4% | −0.24 / 3.0% |

动作发生时零多普勒占比从 ~99% 掉到 ~42%，**能量确实偏离了静止杂波**，
但正负两侧同时升高且幅度接近，线性加权得到的速度停留在 ±0.02~0.10，
与静息基线（±0.08）无法区分。

## 二、四批结果

| 批次 | JUMP 谱宽 | DUCK 谱宽 | 两簇空隙 | 事件命中 |
|---|---|---|---|---|
| 20:08 | 0.362~0.735 | 0.190~0.249 | 0.113 | 10/11 |

四批的两簇**均完全分开**，最小空隙 0.032（20:34），最大 0.113（20:08）。

## 三、判定规则

```
nz_share（5 帧滑窗均值）> 0.30        → 有人在动
动作期间谱宽（5 帧滑窗均值）> 0.255   → JUMP
                          0.16~0.255  → DUCK
                                < 0.16 → 视为晃动，不输出
```

## 四、已知缺陷

- **走动误报**：走动的谱宽落在 0.18~0.24，与蹲重叠。20:34 批静息段出现过 8 次误报。
  候选解法是用方位角变化量做否决项，**尚未验证**。
- **事件切分**：一次蹲有时被切成两个事件（中间短暂回落），计数偏多，分类不受影响。
- **样本单一**：同一人、同一天、同一房间，换人/换场地/改高度均未验证。
