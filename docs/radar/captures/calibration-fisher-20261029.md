# 分析记录：标定数据的 Fisher 可分性（2026-10-29，2 次）

> 输入：2026-10-29 标定采集（3 轮会话：18:34 / 18:40 / 19:03）
> 方法：对 6 类标签（IDLE / LANE_LEFT / LANE_CENTER / LANE_RIGHT / JUMP / DUCK）
> 计算 Fisher 判别比，比较 1T2R 与 2T4R 各组通道对的线性可分性
> 结论：**第一轮数据作废；第二轮 2T4R 通道 0-1 最强（18.8），但样本量只有 4/类**

## 第一次分析（session 20261029-184024）

| 特征组 | Fisher |
|---|---|
| 1T2R 相位差 | **0.000** |
| 2T4R 通道 0-1 | 0.438 |
| 2T4R 通道 1-2 | 0.482 |

各类的 `d1_mean` 全为 `null`，`d2_mean` 全部落在 0.180 ~ 0.183 之间
（IDLE 0.1813、LANE_LEFT 0.1804、LANE_RIGHT 0.1827、JUMP 0.1823、DUCK 0.1824）。

**判读**：六类的特征均值几乎完全相同，等于没有动作信息。这一轮采集
要么人没做动作、要么采到的全是同一状态，**数据不可用于任何结论**。

## 第二次分析（session 20261029-190335）

| 特征组 | Fisher |
|---|---|
| 1T2R 相位差 | 4.455 |
| **2T4R 通道 0-1** | **18.817** |
| 2T4R 通道 1-2 | 1.991 |

各类均值（`d1_mean` / `d2_mean`）：

| 标签 | d1 | d2 |
|---|---|---|
| IDLE | 0.790 | 0.608 |
| LANE_LEFT | **2.065** | 0.063 |
| LANE_CENTER | 1.231 | 0.523 |
| LANE_RIGHT | 0.234 | 0.207 |
| JUMP | 0.932 | 1.536 |
| DUCK | 1.036 | 1.426 |

**判读**：

1. 2T4R 通道 0-1 的 Fisher 是 1T2R 的 **4.2 倍**（18.817 / 4.455），
   说明在这一批数据上，2T4R 的通道对确实比 1T2R 的相位差更能分开类别。
2. LANE_LEFT 的 `d1` 明显偏大（2.065），与 IDLE 的 0.790 拉开距离；
   LANE_RIGHT 的 `d1` 只有 0.234，**几乎贴着 IDLE**——右侧仍然是弱项。
3. JUMP 与 DUCK 在 `d2` 上分别 1.536 / 1.426，**两者非常接近**，
   这与 [vertical-20261029.md](vertical-20261029.md) 里 `same` 的判定一致：
   俯仰维度分不开跳和蹲。

## 局限（必须写清）

- 每类样本 n=4，Fisher 高不代表能实时分类，小样本下极易过拟合。
- 两次分析用的不是同一批有效数据：第一次作废，第二次才可用。
- 本轮只证明「在离线特征上有可分性」，**不等于**实时识别可用；
  按跳蹲验证门，仍需 T1 离线评估与 T2 决策。
